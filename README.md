# Учебный проект по работе над виджетом банковских операций клиента.
## Описание:

это виджет на Python каторы показывает несколько последних успешных операций.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/konanwar/widget.git
```
2. Установите зависимости:
```
pip install 
```
## Структура проекта:
Проект состоит из  3 модулей:
### 1. модуль masks.py
Содержит две функции, скрывает данные счета и карты 
### 2. модуль widget.py
Содержит три функции, возвращает строку с замаскированным номером. Возвращает строку с датой в формате 
"ДД.ММ.ГГГГ". Так же выводит фактическое время подачи запроса на обработку.(Можно отключить)
### 3. модуль processing.py
Содержит две функции, сортирует переданный список операций по статусу выполнения и дате обработки.


## Тестирование и проверка кода
Проект покрыт тестами на pytest (покрытие > 98 %), качество кода контролируется flake8 и mypy.
### Что проверяют тесты
Позитивные сценарии: корректные входные данные, проверка ожидаемого результата.
Негативные сценарии: некорректные типы, пустые строки, неверные форматы, отсутствующие ключи. Ожидаемое поведение — исключение (ValueError, TypeError, KeyError).
Параметризованные тесты: проверка сразу нескольких вариантов входных данных в одном тесте.
Нюансы реализации
В негативных тестах намеренно передаются неверные типы (например, строка вместо списка). Для подавления ошибок mypy используется typing.cast — это явно показывает, что несоответствие типов сделано осознанно.
Параметры тестов, принимающие разные типы (например, wrong_input), аннотируются как Any.
